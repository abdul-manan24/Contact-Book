# Contact-Book
A CLI based contact book project.

## Setup

Install the project and its runtime dependencies:

```powershell
python -m pip install -e .
```

Run the CLI with `python -m contact_book.cli <command>`, for example:

```powershell
python -m contact_book.cli list
```

Run the tests from the project root with:

```powershell
python -m pytest
```
